# Tandoor

Personal recipe store at https://tandoor.kroac.net. The application image is pinned
to 2.6.14; its dedicated database uses PostgreSQL 16.

Run commands from this directory:

```sh
docker compose config --quiet
docker compose up -d --wait
docker compose ps
```

The application and database use the existing external `swarmnet`, matching the
other services on this host. Caddy connects to `tandoor:80`; no host ports are
published. Do not restart Docker or recreate the shared network for this app.

`.env.template` documents configuration. The live `.env` and `.credentials.env`
are ignored by Git and have mode `0600`. The latter holds the `avirut` login,
generated password, API token, token expiration, and the personal space ID. Do
not regenerate secrets or database passwords during routine updates.

The initial owner was created through `/setup/`; signing in initialized its
space, which was named `qm` through the API. Public signup is disabled. No
external API keys are needed for ordinary recipe storage.

Use the supported REST API with `Authorization: Bearer <API_TOKEN>`. Recipes are
at `/api/recipe/`, foods at `/api/food/`, and units at `/api/unit/`. API documentation
is at `/docs/swagger/`, with the schema at `/openapi/`. Do not edit the database
directly for domain operations.

Durable files live under `~/selfhosted/data/tandoor/`: `postgresql/`, `mediafiles/`,
and `staticfiles/`. Back up the database with `pg_dump` and retain media and both
private configuration files. Static files can be regenerated by the application.
For example, write a database dump to a private backup directory using:

```sh
docker compose exec -T tandoor-db pg_dump -U tandoor -d tandoor -Fc > /path/to/private-backup/tandoor.dump
```

Before upgrading, back up persistent data, choose an explicit application
version, pull only this stack, and verify login and API access afterward.
`docker compose stop` preserves the data. Do not remove the data directory.

Upstream deployment reference: [released Compose example](https://github.com/TandoorRecipes/recipes/blob/2.6.14/docs/install/docker/plain/docker-compose.yml).
